ReviewSieve Support

ReviewSieve helps reduce review noise on GitHub pull requests.

Getting help

If ReviewSieve is not working as expected, please include:

  • Your Chrome version
  • Your ReviewSieve version
  • The GitHub pull request URL, if it is public
  • A short description of what happened

Please do not send passwords, one-time sign-in codes, payment card information, or other sensitive credentials.
